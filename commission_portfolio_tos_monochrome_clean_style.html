Free Hosting Guide

Để chia sẻ file HTML này thành một đường link web thực sự cho người khác xem (VD: https://ten-ban.netlify.app), bạn có thể dùng 2 cách cực kỳ đơn giản & 100% miễn phí dưới đây:

Cách 1

Dùng Netlify Drop (Nhanh nhất - 30 Giây)

  1. Lưu mã nguồn file này thành file có tên index.html trên máy tính.
  2. Truy cập trang: app.netlify.com/drop
  3. Kéo thả file index.html vừa lưu vào ô giữa màn hình.
  4. Netlify sẽ tự động tạo một đường link trang web public ngay lập tức để bạn chia sẻ cho mọi người!
Cách 2

Dùng GitHub Pages (Lâu dài & Tùy chỉnh tên miền)

  1. Tạo tài khoản tại github.com.
  2. Tạo một Repository mới (chọn chế độ Public).
  3. Upload file index.html lên Repository.
  4. Vào phần Settings ➔ Pages, tại mục Branch chọn main hoặc master và nhấn Save.
  5. Link web của bạn sẽ có dạng: https://ten-user.github.io/ten-repo/
